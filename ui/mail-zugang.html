Mail-Zugang

Vorgänge Mail-Zugang Einstellungen
Lade Mail-Zugang …
Wozu? Damit Mitglieder die E-Mail mit dem Link von Ihrer Adresse bekommen, braucht SignNext Zugang zu Ihrem E-Mail-Postfach. Das richten Sie einmal ein. Die Zugangsdaten finden Sie in den Hilfeseiten Ihres E-Mail-Anbieters unter „SMTP“.

Zugangsdaten Ihres E-Mail-Anbieters

Steht in den Hilfeseiten Ihres Anbieters als „SMTP-Server“.
Wenn Sie unsicher sind: 465.
Bleibt das Feld leer, wird das bisherige Passwort beibehalten.
So erscheint der Absender beim Mitglied.
Von dieser Adresse bekommen die Mitglieder ihre E-Mail.
Die Kopie enthält den Zugangslink des Mitglieds.

Den Mail-Zugang wirklich löschen? Danach können keine E-Mails mehr an Mitglieder gesendet werden, bis Sie ihn neu einrichten.
